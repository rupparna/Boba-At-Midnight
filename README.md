# boba after dark 🧋🌙

a creepy boba shop that only opens at 11:59pm. made with just html and css, no js, for a YSWS.

## what is this

it's a boba menu but something's off. the drinks are a little too mysterious, there's a "13th drink" nobody's allowed to order, and if you actually place an order... you might regret it.

## files

- `index.html` — the shop
- `order-placed.html` — what happens after you order
- `style.css` — the vibes


## stuff i used

- semantic html (header, main, section, article, footer)
- figure/figcaption for the image
- details/summary for the secret lore
- a form that "sends" you to a second page with zero js
- autoplay audio when you order
- a css-only red glitch effect (turns off automatically if your motion settings are on, don't wanna give anyone a headache)

## how to run

open `index.html`. that's it. no installs, no build stuff.
